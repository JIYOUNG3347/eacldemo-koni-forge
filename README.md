# KONI-Forge — Demo Landing Page

This repository contains **only the landing page** for a live demonstration of
KONI-Forge. It is a single static HTML file, published through GitHub Pages so
that the demonstration has a stable address.

**The KONI-Forge system itself is not in this repository.** The system runs on
dedicated hardware and is reached through the link on the landing page. No
source code, configuration, model weights, or data are published here.

## Contents

| File | Purpose |
|---|---|
| `index.html` | Landing page — description of the demo and a link to the running instance |

## Availability

The demonstration runs on shared research hardware and is **not continuously
available**. When it is offline the landing page says so rather than linking to
a dead address.
